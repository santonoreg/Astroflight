# Cosmic 3D – CosmicView 3D / CosmicDepth 3D για οποιαδήποτε αστροφωτογραφία

Επιλέγεις μια αστροφωτογραφία και η εφαρμογή κάνει ό,τι χρειάζονται ως είσοδο τα δύο scripts του έργου
[Svenesis Siril Scripts](https://github.com/sramuschkat/Siril-Scripts) (Sven Ramuschkat, GPL-3.0):

* **CosmicView 3D** – δείχνει πού κοιτάζει η φωτογραφία σου μέσα στον Γαλαξία: η Γη στον βραχίονα του Ωρίωνα, η φωτογραφία ως
  επίπεδο στην ακριβή κατεύθυνση παρατήρησης, και πτήση «Journey» από τη Γη προς τον στόχο.
* **CosmicDepth 3D** – τρισδιάστατος χάρτης όλων των αντικειμένων του πεδίου (νεφελώματα, γαλαξίες, σμήνη, αστέρια) στις πραγματικές
  τους αποστάσεις.

Τα scripts γράφτηκαν ως plugins του Siril. Εδώ δουλεύουν **χωρίς Siril**: το δικό σου αρχείο, μετά από plate solve με ASTAP, παίζει τον ρόλο της εικόνας του Siril.
Λεπτομέρειες για το τι τροποποιήθηκε: [NOTICE.md](NOTICE.md).

> **Προσοχή:** δεν είναι πτήση *μέσα* στο νεφέλωμα με στρώματα αερίου. Είναι χάρτες/πτήσεις σε κλίμακα Γαλαξία, με τη φωτογραφία ως
> επίπεδο στον χώρο. Οι αποστάσεις προέρχονται από το SIMBAD/NED/Gaia (χρειάζεται internet την πρώτη φορά).

## Εγκατάσταση

```
pip install -r requirements.txt
```
Χρειάζεσαι και τον **ASTAP** με μία βάση αστεριών (D50 ή D20) από https://hnsky.org/astap.htm — εκτός αν η εικόνα σου είναι FITS που έχει ήδη λυθεί (π.χ. από το Siril).

## Χρήση

```
python launcher.py
```
1. **Επιλογή εικόνας** (TIFF / PNG / JPG / FITS).
2. Έλεγξε ότι βρέθηκε ο ASTAP (✔) – αλλιώς πάτα «Αναζήτηση» ή «…».
3. *(Προαιρετικά)* κάμερα και εστιακή (π.χ. Atik 383L+, 300 mm → ονομαστικά 3.71″/pixel) και **όνομα αντικειμένου** (π.χ. `Rosette Nebula`): επιταχύνουν και σιγουρεύουν το plate solve και δίνουν τον στόχο στο CosmicView. **Δεν χρειάζεται να ξέρεις την κλίμακα**: αν δεν τη δώσεις (ή αν η εικόνα είναι mosaic/έχει αλλάξει μέγεθος, οπότε η ονομαστική δεν ισχύει), δοκιμάζονται αυτόματα πολλές κλίμακες.
4. **▶ Προετοιμασία εικόνας**: διαβάζει την εικόνα, κάνει plate solve (με πρόοδο και δυνατότητα ακύρωσης) και αποθηκεύει FITS με WCS στον φάκελο `~/.cosmic3d/work/`. Για την ίδια εικόνα η λύση ξαναχρησιμοποιείται.
5. Πάτα **🌌 CosmicView 3D** ή **📊 CosmicDepth 3D**· στο παράθυρο του script πάτα «Render» όπως στο upstream (οδηγίες στο `docs/`).

Κάθε ρύθμιση έχει επεξήγηση από κάτω. Από τη γραμμή εντολών:

```
python launcher.py --image foto.tif --open view --pixel 5.4 --focal 300 --object "Rosette Nebula"
python launcher.py --image foto.tif --prepare-only        # μόνο plate solve, χωρίς γραφικά
```

## Πώς γίνεται το plate solve (και αν αποτύχει)
Η εικόνα μικραίνει (μέχρι ~2800 px) πριν σταλεί στον ASTAP και τα μηδενικά περιθώρια ενός mosaic αντικαθίστανται με φόντο. Δοκιμάζονται με σειρά: (1) οι κλίμακες από τα οπτικά σου (ονομαστική, ×2, ×3, ×0.5), (2) τυφλή αναζήτηση, (3) σκάλα κλιμάκων 0.7–80″/px, (4) τυφλή αναζήτηση σε αργή λειτουργία. Με όνομα αντικειμένου η αναζήτηση περιορίζεται σε ±20° και γίνεται πολύ ταχύτερη και σίγουρη. Η πρόοδος δείχνει ποια δοκιμή τρέχει· μπορείς να ακυρώσεις.

Αν όλες αποτύχουν, το μήνυμα λέει τι δοκιμάστηκε και τον κωδικό του ASTAP. Τότε ελέγχεις: (1) ότι έχει εγκατασταθεί βάση αστεριών (D50/D20)· (2) ότι η βάση καλύπτει τόσο ευρύ πεδίο (mosaic > ~6°)· (3) ότι έδωσες όνομα αντικειμένου. Αν είναι τσεκαρισμένη η «προσεγγιστική λύση» και έχει δοθεί όνομα και κλίμακα, χρησιμοποιείται εφεδρικά WCS με κέντρο το αντικείμενο, κλίμακα από τα οπτικά σου και βορρά πάνω· σημαίνεται πάντα ως **προσεγγιστική** (κάρτα `APPROX` στο FITS).
